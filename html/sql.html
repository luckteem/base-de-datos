DATABASE 101

2. Estructura base

TABLA

Es el objeto que guarda datos. Ejemplo: clientes

CAMPO

Cada atributo o columna. Ejemplo: nombre, email

REGISTRO

Una fila completa. Ejemplo: (1, 'Ana', 'ana@mail.com')

1. Normalización - Teoría Completa

¿Qué es Normalización?

Es el proceso de organizar las tablas para evitar redundancia (datos repetidos) y anomalías al insertar, borrar o actualizar.

Objetivo: que cada dato se guarde una sola vez.

1FN - Primera Forma Normal

Los valores deben ser atómicos, no se pueden guardar listas en un campo.

Mal: campo telefonos = "11-1234, 11-5678"

Bien: crear tabla telefonos separada.

2FN - Segunda Forma Normal

Solo si hay clave compuesta. Cada campo debe depender de TODA la clave, no de una parte.

Si tu clave es (id_pedido + id_producto), el nombre del producto no debe estar ahí, va en otra tabla.

3FN - Tercera Forma Normal

Sin dependencia transitiva. Un campo no puede depender de otro campo que no es clave.

Ejemplo: En tabla clientes no guardes pais y nombre_pais, solo id_pais. El nombre del pais va en tabla paises.

Diccionario de Datos

Es el plano de tu base de datos. Documento donde defines cada tabla, qué guarda, qué tipo de dato es cada campo, sus claves y relaciones.

Ejemplo: Tabla clientes - id es INT y es PRIMARY KEY, email es VARCHAR(100) y es UNIQUE.

2. GROUP BY y Agregación - Teoría Completa

Funciones de Agregación

Resumen muchas filas en un solo valor.

COUNT() cuenta filas. SUM() suma. AVG() promedia. MAX() trae el más grande. MIN() trae el más chico.

SELECT COUNT(*) as total_clientes FROM clientes; SELECT AVG(edad) as promedio_edad FROM clientes;

GROUP BY

Agrupa filas que tienen el mismo valor para poder contar o sumar por grupo.

Sin GROUP BY, COUNT cuenta toda la tabla. Con GROUP BY cuenta por cada país, por cada ciudad, etc.

SELECT pais, COUNT(*) as cantidad FROM clientes GROUP BY pais;

Esto te devuelve: AR tiene 10, BR tiene 5, CL tiene 3.

HAVING vs WHERE

WHERE filtra ANTES de agrupar. Filtra filas.

HAVING filtra DESPUÉS de agrupar. Filtra grupos.

SELECT pais, COUNT(*) as total FROM clientes WHERE edad > 18 GROUP BY pais HAVING total > 5;

Acá WHERE deja solo mayores de 18, GROUP BY los agrupa por país, y HAVING deja solo los países con más de 5 clientes.

JOINS - Concepto

Sirven para unir datos de dos o más tablas en una sola consulta usando una clave en común. Sin JOINS tendrías que hacer dos consultas separadas.

3. Comandos SQL

SELECT y FROM

SELECT indica qué columnas quieres ver y FROM de qué tabla las sacas. Son obligatorios en toda consulta.

SELECT nombre, email FROM clientes;

WHERE

WHERE filtra filas. Solo trae los registros que cumplen una condición específica.

SELECT * FROM clientes WHERE pais = 'AR';

INSERT INTO

INSERT INTO sirve para agregar un nuevo registro a una tabla.

INSERT INTO clientes (nombre, email) VALUES ('Juan', 'juan@mail.com');

LIKE

LIKE busca patrones con % que significa cualquier cosa.

%A busca que termine en A. A% que empiece en A.

SELECT * FROM clientes WHERE nombre LIKE 'A%';

LIMIT

LIMIT limita la cantidad de resultados devueltos. Muy útil para no traer 10.000 filas.

SELECT * FROM clientes LIMIT 10;

Funciones de Agregación

Resumen datos de muchas filas en una sola.

COUNT() cuenta, SUM() suma, AVG() promedia, MAX() y MIN() traen extremos.

SELECT COUNT(*) as total, AVG(edad) as promedio FROM clientes;

GROUP BY

GROUP BY agrupa filas con el mismo valor para poder aplicar funciones de agregación por grupo.

SELECT pais, COUNT(*) FROM clientes GROUP BY pais;

HAVING

HAVING filtra grupos después de agrupar. WHERE filtra filas, HAVING filtra grupos.

SELECT pais, COUNT(*) as total FROM clientes GROUP BY pais HAVING total > 5;

INNER JOIN

Solo trae coincidencias que existen en ambas tablas.

SELECT c.nombre, p.monto FROM clientes c INNER JOIN pedidos p ON c.id = p.cliente_id;

LEFT JOIN

Trae todos los clientes, aunque no tengan pedido. Si no hay match, trae NULL.

SELECT c.nombre, p.monto FROM clientes c LEFT JOIN pedidos p ON c.id = p.cliente_id;

RIGHT JOIN

Trae todos los pedidos, aunque no tengan cliente.

SELECT c.nombre, p.monto FROM clientes c RIGHT JOIN pedidos p ON c.id = p.cliente_id;

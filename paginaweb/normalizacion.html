2. Normalización

Evita repetir datos. Divide en tablas.

1FN: Un valor por celda. No listas.

2FN: Si la clave es compuesta, todo debe depender de toda la clave.

3FN: No guardes datos que dependen de otro dato no clave.

CREATE TABLE paises (id INT PRIMARY KEY, nombre VARCHAR(50)); CREATE TABLE clientes (id INT PRIMARY KEY, nombre VARCHAR(50), pais_id INT);

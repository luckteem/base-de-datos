2. Normalización evitar redundancia

¿Qué es?

Proceso para evitar redundancia. Cada dato se guarda una sola vez.

1FN

Valores atómicos. No listas en un campo.

Mal: telefonos="11-1234, 11-5678"

2FN

Depende de TODA la clave compuesta.

3FN

Sin dependencia transitiva. Solo id_pais, no nombre_pais.

Diccionario de Datos

El plano de tu BD. Defines tipo de dato, claves y relaciones. Ej: id INT PRIMARY KEY.

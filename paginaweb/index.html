1. Estructura Base

Objeto que guarda datos. Ej: clientes

2. Normalización

¿Qué es?

Proceso para evitar redundancia. Cada dato se guarda una sola vez.

1FN

Valores atómicos. No listas en un campo.

Mal: telefonos="11-1234, 11-5678"

2FN

Depende de TODA la clave compuesta.

3FN

Sin dependencia transitiva. Solo id_pais, no nombre_pais.

Diccionario de Datos

El plano de tu BD. Defines tipo de dato, claves y relaciones. Ej: id INT PRIMARY KEY.

3. GROUP BY y Agregación

Funciones

COUNT() cuenta, SUM() suma, AVG() promedia, MAX() y MIN() extremos.

SELECT COUNT(*) FROM clientes;

GROUP BY

Agrupa por el mismo valor para contar por grupo.

SELECT pais, COUNT(*) FROM clientes GROUP BY pais;

HAVING vs WHERE

WHERE filtra filas antes. HAVING filtra grupos después.

SELECT pais, COUNT(*) as total FROM clientes GROUP BY pais HAVING total > 5;

4. Catálogo SQL

SELECT y FROM

SELECT nombre FROM clientes;

WHERE

SELECT * FROM clientes WHERE pais='AR';

INSERT INTO

INSERT INTO clientes (nombre) VALUES ('Juan');

LIKE y LIMIT

SELECT * FROM clientes WHERE nombre LIKE 'A%' LIMIT 10;

JOINS

INNER: solo coincidencias. LEFT: todo de la izq.

SELECT c.nombre, p.monto FROM clientes c INNER JOIN pedidos p ON c.id = p.cliente_id;

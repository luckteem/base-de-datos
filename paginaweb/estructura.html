1. Estructura

Tabla: Donde se guardan datos. Ej: clientes.

Campo: Columna. Ej: email.

Registro: Una fila. Ej: (1, Ana).

Claves

PK: ID único. Ej: id INT PRIMARY KEY

FK: Apunta a otra tabla. Ej: cliente_id

Tipos

INT, VARCHAR(100), TEXT, DATE, DECIMAL(10,2)
